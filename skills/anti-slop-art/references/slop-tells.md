# Slop tells -> replacements

| Tell | Why it reads as AI/template | Replace with |
|---|---|---|
| Neon gradient on dark | Default "futuristic" prior | Pick a real-world palette (print inks, tropical postcard, thrift-store packaging); allow a light background |
| Emoji sprites | Zero authorship | Hand-authored SVG/pixel sprites with outlines in the tokens |
| Perfect circles/rects | No drawing decisions | Silhouette-first shapes: tapered, notched, asymmetric |
| Inter + rounded buttons | Library default | Chunky display face, buttons built from the world's material (wood tag, sticker, ticket) |
| Glass panels | Dribbble default | Opaque panels with a clear edge treatment, paper/metal/cloth texture |
| Everything centered | No hierarchy | Anchor HUD to corners with different weights; one hero element 2-3x larger |
| Linear tween | No physicality | Overshoot, anticipation, settle; stagger list items by 30-60 ms |
| Silent/boring audio | Afterthought | 3-layer SFX with pitch variance, music stem that reacts to danger |
| Generic copy | Autopilot voice | Concrete verbs and jokes tied to the world; max 6 words per prompt |
| Static background | Flat | 3 parallax layers + ambient particles + subtle color grading per level |
| Uniform difficulty | Unauthored | Authored beats: teach, test, twist, breather |
| Stock "AI art" + vector HUD | Style collision | Palette-map and grain the raster, or redraw to match |

## Quick self-test (60 seconds)
1. Blur the screenshot: can you still tell player, hazard, goal?
2. Cover the logo: could this be any of 1,000 other games?
3. Squint at the palette: more than 6 hues competing?
4. Mute the video: does the motion alone communicate impact?
5. Read all text aloud: any sentence you've seen in 100 other games?
